# cursor-code-review-workflow

Cursor CLI code review as a composite GitHub Action, built around restricted
autonomy: the agent writes `review.md` and nothing else, and the Action posts the
review comment from a deterministic workflow step.

Repository conventions are in [AGENTS.md](AGENTS.md), the contribution flow in
[CONTRIBUTING.md](CONTRIBUTING.md), and the security policy in
[SECURITY.md](SECURITY.md).

Caller documentation ships alongside the Action.
